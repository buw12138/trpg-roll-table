# 随机生成器（TRPG 离线版）

给跑团主持人用的随机生成器：建表、掷表、把几张表拼在一起一次生成一个 NPC。
**纯前端、零依赖、零服务器**，所有数据存在你自己的浏览器里，可导出 / 导入 JSON 迁移。

---

## 交付物

| 路径 | 说明 |
| --- | --- |
| `随机生成器.html` | **主交付物**。双击即用（437 KB，单文件，无外链、无网络请求） |

手机打开：把 `随机生成器.html` 传到手机（微信/网盘/数据线都行），用浏览器打开即可，无需安装。

## 30 秒上手

1. 双击 `随机生成器.html`。
2. 首次打开已载入「即兴核心包」（80 张表 / 1152 条 / 9 个组合），先点侧栏 **组合 → 完整 NPC → 掷出组合** 看看效果。
3. 想从零开始：右上 **导入 / 导出 → 备份 → 新建空白表组**。
4. 自己建表：侧栏 **随机表 → 新建表** → 逐条填写，或点 **批量粘贴** 把整段列表贴进去（一行一条）。
5. 表多了就归类：侧栏底部 **+ 分组** 建文件夹，再把表拖进去（或点表行右侧 `⋯` → 移到某分组）。
6. 建完就按 **掷！**（或按空格）；满意的结果点 **收藏**，在收藏夹里写备注；收藏卡上的「加入文本卡库」可以直接变成追踪面板里的文本卡。

## 内置表包：即兴核心包

首次打开、菜单「载入核心表包」、以及旧数据迁移，载入的都是这一包。按四组目录组织，共 **80 张表 / 1152 条 / 9 个组合**。

| 04 事件与遭遇 | 9 | 128 | 旅途遭遇（d20）· 营地事件 · 任务委托四件套（委托人 / 目标 / 报酬 / 隐患）· 尸体搜刮三件套（随身物 / 贴身藏物 / 故事线索） |

04 组是给八个组合做支撑的最小集（委托四件套、尸体三件套本质属于扩展包内容），所以表数比最初估的 45 张多；把它们删掉，`任务委托` 与 `尸体搜刮` 两个组合会直接显示「表已删除」。

### 权重约定（战斗描述尤其重要）

战斗类表内分两档：**普通描述 5 : 戏剧化 1**（约 85% : 15%）；`致命一击·物理` / `致命一击·法术` 反过来，戏剧化占 5 : 1。所有条目都不写伤害数值，只写画面，直接套在掷骰结果上。

想改观感就直接改条目权重：5 改 3 会更常出戏剧化描述，改 0 则永不抽到；改完不用重掷，下一次就生效。

### 九个组合

`酒馆一夜`、`地牢房间`、`旅途一天`、`城市街区`、`完整 NPC`、`战斗片段`、`任务委托`、`尸体搜刮`、`初遇一个陌生人`。

字段都固定绑到了对应表，结果卡上可对单个字段「重掷」，也可以先锁住满意的字段再整组掷。`战斗片段` 用的 `命中描述` / `受创反应` 是分流表——掷到时再去明细表抽一次，所以每次的打击类型（挥砍 / 法术 / 箭矢…）与受创类型（野兽 / 构装 / 死亡 / 溃逃…）都是随机的；想固定某种打法，把组合字段直接换成 `命中·挥砍` 之类的明细表即可。

### 旧版「泛奇幻示例表组」已清空

旧版那 11 张测试表（姓氏 / 名字 / 绰号 / NPC 姓名 / NPC 外貌 / NPC 性格 / NPC 动机 / NPC 口癖 / 天气 / 旅途遭遇 / 酒馆传闻）已从内置内容里删干净。用过旧版的浏览器下次打开会自动迁移一次：

1. 只在「表组名是泛奇幻示例表组」或「现有表全部属于那 11 张测试表」时替换；
2. 你自己建的表、改过的表组一律不动；
3. 迁移前先存快照，在 导入 / 导出 → 备份 里能找回，会有一次提示。

## 战役 / 笔记 / 记录表

**战役是容器**：一个战役 = 一个世界或一条故事线。点侧栏「战役」→ 新建战役 → 在战役下的模块里管内容。

- 新建战役默认套用**备团模板**：一条「备团八步」清单 + 一张空白会话工作表 + 角色 / NPC / 战役规划骨架，全部可删改。
- 顶部下拉切换战役；右侧按钮可改名、导出本战役（`.md`）、删除（会先列出将一并删除的笔记条数与记录项数）。
- 侧栏是当前模块的条目列表；模块子页签在顶部（`笔记` / `记录表`，以后可继续加）。

**笔记**：清单或自由笔记。六种模板快速建条（备团八步 / 秘密与线索 / 场景 / NPC 速记 / 怪物 / 宝物），支持勾选、置顶、加条目、复制全文、按关键词与完成状态筛选。

**记录表**：记录表 = **模板（结构） + 实例（数据）**。模板是全局的，任何战役都能用同一份模板新建记录；实例按战役存。

**内置模板**（可改可复制、不可删；删了会按内置定义自动补回）

| 模板 | 内容 |
| --- | --- |
| 会话工作表 | 场次 / 日期 + 8 个备团问题，每场新建一份，可「复制本份」 |
| 角色追踪 | 6 列表格（角色名 / 玩家 / 种族职业 / 背景 / 理念特质缺陷羁绊 / 备注） |
| NPC 追踪 | 重复组：名字 / 原型 / 显著数据 / 与队伍互动 / 备注 |
| 战役规划 | 钩子 + 世界六条真相（每行三列）+ 三条前线（重复组，目标 + 三个凶兆） |

**模板编辑器（所见即所得）**：记录表 → 模板管理 → 编辑 / 新建模板。

- **布局是 12 列栅格**：每个组件有「起始列 + 跨列」。两个短组件各占 6 列就会自动并排；想在右边留白就把起始列改成 7。
- **容器**：`行`（横排）和 `分组`（带标题的框），最多套两层；拖到行 / 分组内部就变成它的子项。
- 左侧组件库拖进画布任意位置，或单击加到当前选中容器；画布上的组件可以拖 ⠿ 移动、拖右边缘改宽度、`⧉` 复制、`×` 删除。
- 右侧检查器改标签、占位提示、行数、下拉选项、表格列、重复组字段、方块格数、起始列 / 跨列；行可调间距，分组可改标题 / 外框。选中任意组件时，检查器顶部会写明它的用途和适用场景；组件库悬停也有同样的提示。
- 画布直接用真实渲染器，输入框里填的是**示例值**，保存后会跟着模板一起记住；「成品预览」隐藏全部手柄与虚线框。
- 撤销 / 重做（`Ctrl+Z` / `Ctrl+Y`）、草稿自动保存（关页面不丢，重开自动恢复）、导出 / 导入模板 JSON。
- 旧的扁平模板会在首次加载时自动转成新布局，组件 id 不变，已有记录的数据不丢。

**卡片模板**：模板库同时管理 `敌人卡 / 环境卡 / 玩家卡 / 文本卡 / 特殊卡` 五套内置模板，组件是 `标签组 / 段落 / 标签值行 / 数值行 / 方块追踪 / 计数条 / 特性列表 / 备注`。方块追踪用于生命点、压力点、希望点这类小数值，点一下标记一格；计数条自带 `− 值 / 上限 ＋` 与进度条；特性列表默认只显示标题行，点开看描述。卡片目前用在「追踪面板」上。

**老的固定四表会自动迁移**：首次打开带旧数据的战役时，`sessions / characters / npcs / planner` 会被转成对应模板的实例（旧字段保留在本地数据里，不删）。

**版本说明**：模板改版会递增 `version`；已存在的实例按当前模板渲染，删掉的组件其旧值仍留在数据里，加回去就能重新显示。

**以后加功能**：新模块只要 `RT.ws.register({ id, key, view, side, count, seed, exportMd })`，外壳、侧栏、备份会自动接上，不用改 `20-app.js`。

## 追踪面板（DM 白板）

战役下的第三个页签，给战斗 / 探索时临时摆东西用。

**布局**：左侧栏就是「卡片库」，主区整块留给白板。敌人、环境、玩家、文本、特殊共用一个库，靠类型 / 搜索 / 筛选区分，用的是不同的卡片模板。

**库**
- 数据不内置，首次使用先导入：卡片库「导入」→ 选 `敌人数据库.json` / `环境数据库.json` / `玩家角色卡.json`（也支持把文件直接拖进侧栏）；会按内容自动识别类型，纯文本按每行一条存为文本卡。
- 玩家卡会完整带出：属性（敏/力/巧/本能/风度/知识）、生命 / 压力 / 希望 / 护甲槽、阈值、背景 / 外貌 / 动机、卡组效果（职业 / 子职 / 种族 / 社群描述）、武器护甲、金币、物品与经历。
- 搜索名称 / 简介 / 标签，按类型（敌人 / 环境 / 玩家 / 文本 / 特殊）、来源、位阶、种类筛选；按名称 / 类型 / 位阶 / 种类 / 来源排序。
- 支持新建（先选卡片类型，再从这一类里的模板中选一个）、编辑数据、重命名、删除；「导出json / 导出TXT」整库导出。
- **特殊卡**：新建时除内置特殊卡模板外，还能选你自己搭的卡片模板（可在「模板管理」里建）。内置的特殊卡模板就是「计数条 + 备注」，适合倒计时 / 恐怖时钟这类追踪。
- 侧栏工具栏的「模板管理」与记录表那边的模板管理是**同一个模板库**：同一份列表、同一套新建（记录表 / 敌人 / 环境 / 玩家 / 特殊 / 文本），每个类型都能复制或自建变体，不再有单独的「自定义卡片」分类。

**白板**
- 点条目 = 在视口中央放一张卡（默认宽 220，可在工具栏改）；也可以把条目直接拖到白板上指定位置。
- 拖卡片标题栏（整条都算，含 `⠿`）移动、拖右边缘改宽度，点一下自动置顶；双击标题或右键菜单可重命名；右键菜单还有 编辑数据 / 刷新模板 / 复制 / 置顶 / 锁定 / 移除。
- 生命 / 压力等方块点一下标记一格；难度、阈值等数字原地改；备注直接写；特殊卡的计数条用 `− / ＋` 或直接改数字；特性列表点标题展开 / 收起。
- **常驻骰子条**：面板顶部一直有「通用骰 / 二元骰」选择、掷法（普通 / 优势 / 劣势）、公式输入、掷骰按钮和结果。通用骰支持多骰项、加减乘除、括号、取高取低：`1d20+1d6+8`、`2d6+3`、`4d6kh3`、`2d20kh1`、`(1d8+2)*2`、`d66`；优势 / 劣势既可选下拉，也可在公式里写 `adv` / `dis`。二元骰固定 2d12（希望 / 恐惧，双同暴击），可填调整值，优势 / 劣势额外 +1d6 / −1d6，调整值与加骰都计入合计。点「?」看完整写法。最近一次结果会随面板保存。
- 拖空白处平移；`Ctrl + 滚轮` 以光标为中心缩放（40%–200%）；右下角 `− 100% + 适应`。
- 工具栏只留「宽度 / 导出面板 / 导入面板 / 清空」；新卡片统一从左侧卡片库的「新建」进。
- 「宽度」控制之后新放的卡片默认宽度。
- 「清空」只清面板（二次确认）；「导出 / 导入」是整块面板的 JSON，导入按合并处理。

**数据位置**：面板按战役存（换战役就是另一块板），库与卡片模板全局共享；工作区备份会一起带走。

## 规则速查

全局面板，明摆着是「桌面 GM 挡屏」：

- **导入**：`.md` / `.txt` / `.json`，可点选文件、拖进文本框，或直接粘贴；JSON 支持 `{name, md}`、`{name, blocks:[…]}`、`{packs:[…]}`。
- **格式规范内置**：速查页 →「格式说明」查看完整规范（语法支持范围、JSON 字段与 blocks 类型、命名去重、常见错误），并可下载示例 `.md` / `.json` 直接导入试。同样内容也放在仓库旁 `规则包格式说明.md`。
- **解析**：标题 / 列表 / 表格 / 引用 / 分隔线 / 代码块 / 粗体 / 行内码 / 链接；`#`~`####` 自动进左侧目录（1–3 级），UTF-8 带 BOM 也能导入。
- **多包切换 + 搜索**：左侧切规则包，右侧正文；搜索会高亮正文并过滤目录。
- **摘录到别处**：正文里选中一段文字，会浮出「加入收藏 / 文本卡库」；左侧目录每行悬停出现 `＋`，可以把整个分级（含子标题与列表）一次性加入收藏或文本卡库。
- **不预置内容**：按需导入。仓库旁的 `规则包_5E速查.md` 是可选示例，导入即用（也可删）。

## 工作区备份

单表组导出（`导出` 页）只管随机表；**工作区备份**（`工作区` 页）打包全部：

```
{ kind:'trpg-workspace',
  set:      全部表与组合,
  campaigns: 战役列表,
  modules:  { 笔记, 记录表, 追踪面板, …（按模块注册表遍历） },
```

## 核心概念

**表（Table）**：一组条目。例：`外貌·显著特征`。表名不可重复——新建与改名都会校验，重名会被拒绝；复制表时自动加「副本 / 副本 2」。
**分组（Folder）**：侧栏里的文件夹，用来收纳同类表；可以**嵌套成树**，层数不限（建议 2–3 层）。
**条目（Entry）**：表里的一行文字，可带权重、可带骰值区间。
**权重**：默认 1。权重 8 与 1 的比例约为 8:1；权重 0 表示永不抽到。内置战斗表用 5:1 区分「普通描述 : 戏剧化描述」。
**骰子区间**：给表填一个骰子表达式（如 `1d100`），再给条目填「起–止」，则先掷骰再按区间取条目——适合还原纸面 d100 表。
**组合（Combo）**：把多张表排成字段，一次分别抽取，再用模板拼成整段文字。例：姓名 + 外貌 + 性格 + 动机 + 口癖 → 一个 NPC。
**收藏（Favorite）**：掷出的结果（单表或组合）可一键收藏，并附一段手写备注，例如「第 3 章酒馆老板，玩家欠他 20 金币」。

---

## 分组怎么用（支持嵌套）

- **新建**：侧栏底部「+ 分组」建根级分组；在分组标题右侧 `⋯` → 「新建子分组」建下一层。
- **移动表**：把表行拖到任意分组标题上；不想拖就点表行 `⋯` → 菜单里按层级缩进列出所有分组，选一个。
- **移动分组**：直接拖分组标题到另一个分组标题上（不能拖进自己或自己的子分组，会提示）。
- **折叠**：点分组标题，折叠会连带隐藏其下所有子分组；状态会保存。
- **一键展开 / 收起**：搜索框下方两个按钮，对整棵分组树一次生效（层数再多也不用一个个点）；状态同样会保存。表很多时先「收起」，找表更快。
- **改名 / 删除**：分组标题右侧 `⋯`。删除时可选「内容移到上一级」或「全部删除」——前者把表与子分组提升到父级，后者连子树一起删（都会先存快照）。
- 搜索结果自动展平，不受折叠影响；组合的字段下拉按分组路径归类（如 `NPC 人物 / 名字组件`）。

## 语法速查

| 写法 | 位置 | 作用 |
| --- | --- | --- |
| `{表名}` 或 `[[表名]]` | 条目正文 | 掷到这条时，再从那 张表抽一次并展开。最多 8 层，自动检测循环引用 |
| `1d100`、`2d6+1`、`d66` | 表的「骰子」输入框 | 与条目的「起–止」区间配合使用；区间外的骰值取最近一条并给出提示 |
| `{字段名}` | 组合的「成品模板」 | 用该字段的取值替换；模板留空则按「字段：值」逐行列出 |
| `文本\|权重` | 批量粘贴 | 例：`莉安·银溪\|3` |
| `文本\|起-止` | 批量粘贴 | 例：`盗匪出现\|10-11`（该表需先填骰子表达式） |

**结果可复现**：每次掷出都会记录 `seed`。历史里点「重放」，会用同一种子重跑一遍，得到完全一样的结果（前提是表内容没改过）。

## 表名唯一

- **新建表**：弹窗里输入名字，若与已有表重名（忽略大小写与首尾空格），下方提示「已有同名表」且「确定」按钮禁用，必须改名才能创建；取消则不会建表。
- **改名**：直接在标题上改，重名时输入框转红并提示；失焦后自动还原成原名，不会写入。
- **复制表**：自动取一个不冲突的名字（`X 副本`、`X 副本 2`…）。
- 导入的 JSON 若本身包含同名表，仍允许导入（历史数据可能如此），但掷表引用时会显示同名警告。

## 导入 / 导出

右上 **导入 / 导出** 里四个页签：

- **导出**：下载 `.json`（含分组、表、组合、收藏与备注、历史）。也可「复制」后自己贴到别处。
- **导入**：选文件、或直接粘贴 JSON；也可以把 `.json` 拖进窗口。三种策略：
  - **合并到当前表组**（默认）：保留现有数据，追加导入内容；重名的分组 / 表 / 组合会自动换新 id 并同步引用。
  - **作为新表组载入**：整体替换为导入内容，名称加「（导入）」。
  - **覆盖当前表组**：整体替换。
  - 任何导入前都会先存一份自动快照。
  - 旧版（v1，没有分组）导出的 JSON 也能直接导入：表会全部落在「未分组」。
- **CSV**：给 Excel 用。列顺序 `文本, 权重, 区间起, 区间止`（后三列可空），可导出当前表、也可粘贴导入（追加/覆盖）。
- **备份**：最近 3 次破坏性操作（删表、导入、恢复）前的自动快照，可一键恢复；也是新建空白表组 / 重新载入「即兴核心包」的入口。

### 多端同步（无服务器）

```
设备 A：导入/导出 → 导出 → 得到 随机生成器-表组-YYYYMMDD-HHMM.json
          ↓（网盘 / 微信 / U 盘）
设备 B：导入/导出 → 导入 → 选择文件 → 合并（或覆盖）
```

没有自动同步，这是刻意的：不联网、不上传任何内容。

## 打包成 App（可选）

单文件版在所有平台都能通过浏览器直接用，以下是想要"图标 + 独立窗口"时的做法。

### PWA（安卓/iOS 主屏幕图标）

`pwa/` 已经准备好，但它需要 **http(s)** 才能注册 Service Worker（`file://` 不支持）：

```powershell
# 在 随机生成器 目录下起一个本地静态服务（只监听本机）
python -m http.server 8791 --bind 127.0.0.1
# 浏览器打开 http://127.0.0.1:8791/pwa/index.html
```

要装到手机，需要把 `pwa/` 目录放到任意静态托管（GitHub Pages / 内网 nginx 均可，仍无后端）。

### APK

用 [Capacitor](https://capacitorjs.com/) 或 [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) 把 `pwa/` 包一层即可，数据仍在本机 WebView 里。
需要本机装 JDK 17 + Android SDK（约 5–10 GB）。

### Windows / macOS 桌面窗口

[Tauri 2](https://v2.tauri.app/) 指向 `pwa/` 目录即可，产物约 5 MB（需 Rust 工具链）。

## 已知限制

- **数据在浏览器本地**：清浏览器站点数据 / 换浏览器 / 换设备都会"丢"，请定期导出。随机表用「导出」，笔记 / 记录表 / 追踪面板 / 规则速查 / 库用「工作区」备份。工具会在删除与导入前自动存快照，但快照同样在本机。
- **战役数据不进表组导出**：`导出` 页只导出随机表；战役 / 笔记 / 记录表 / 追踪面板 / 库 / 规则速查请走 `工作区` 页。这是刻意的——表组格式保持向后兼容，旧文件仍可导入。
- **规则速查是 Markdown 子集**：不支持嵌套列表、脚注、图片、HTML 内联；表格需要标准 `| a | b |` 与分隔行。
- **记录表模板改动影响所有实例**：模板是共享的，改结构后已有实例按新结构渲染（旧值保留但不显示）。想给不同战役不同结构就复制模板再改。
- **模板是 12 列栅格，不是像素画布**：位置用「起始列 + 跨列」表达，窄屏会按模板的「自动堆成一列」设置重排；这样手机与打印都不会错位。容器最多套两层。
- **旧模板自动迁移**：首次打开会自动把旧 `trpg_rt_sheet_templates_v1` 转成新布局并删除旧 key（组件 id 不变，实例数据无损）。转换失败会原样保留旧 key 并回退内置模板。
- **追踪面板的库不内置数据**：卡片库首次使用要自己导入根目录那两份 JSON（或从旧设备工作区恢复）；库是全局的，面板内容按战役存。
- **卡片会复制描述文本**：一板 20 张环境卡约 100–150KB，接近 localStorage 上限时会提示先导出。
- **重复组不支持嵌套**：重复组内可放文本 / 数字 / 日期 / 勾选 / 下拉 / 清单行，但不能再套重复组或表格。
- **`file://` 与 `http://` 是两套存储**：同一个 html 用双击打开和用本地服务器打开，看到的数据不互通。选定一种方式长期使用。
- **移动文件位置**：部分浏览器把 `file://` 的存储与路径绑定。要挪动 html 之前，先导出一次。
- **存储上限**：浏览器一般给 localStorage 5 MB 左右。文本表能装几万条，接近上限时会提示导出。
- **单轮不重复**：一次抽 N 条时同轮内不重复；跨轮会重复，这是设计使然（掷表本来就有放回）。
- **CSV** 只搬条目，不搬表结构 / 组合 / 骰子设置。

## 常见问题

**Q：换电脑后数据没了？**
导出 JSON 再导入。浏览器数据不会跟着文件走。

**Q：点「下载」没反应？**
某些环境（如内嵌 WebView）会拦截下载。改用弹窗里的「复制」，粘贴到记事本另存为 `.json`。

**Q：手机上界面挤？**
窄屏自动切成单列 + 底部六个页签（可横滑）；左上角按钮打开表列表 / 战役列表。结果卡在同一页往下滚。

**Q：想给玩家看结果？**
结果面板支持右上角 A−/A+ 调字号，也可直接用浏览器打印（已做打印样式，会隐藏工具栏）。
